# FORZERO: BUDGET · 有限竞速：地贫线

纯代码驱动的 WebGL 2 三维自行车与多载具竞速游戏——零外部美术资源包、零 npm 运行时依赖，全部场景、建筑、植被、3D 车辆与动态骑行音效均由程序化代码生成。

玩家可在 **深圳大学 · 粤海校区（荔园环骑）**、**伦敦 Bloomsbury（UCL）** 与 **佛山顺德 · 顺峰山公园** 三张立体地图间自由骑行与站台旅行，挑战 20 条固定赛道、种子赛道 v2 与每周挑战。

发车区可选单人计时、三车 AI 竞速、1v1、**影子追捕**与**夜骑盲区**。固定赛道可反向，闭环赛道可选 1–3 圈；全屏俯视地图接入 **「地图点选路线工坊」**（生成 `R1...` 路线代码直接开跑或建房）。AI 提供标准和强劲两档，完赛俯视地图支持双车回放。车库提供 ¥400、¥700 和不限预算三档，支持四载具通用自定义骑手皮肤（`SkinModelSpec`）。所有配件直接开放，违禁魔改成绩仅用于娱乐。联机请使用 2.5.5（协议 v3，支持 **联机捉人 · 1 追 N 三轮轮换**）。

手机默认使用精简 HUD，可在「设置 → HUD 缩放」切换自动、65%、80%、100%、115% 或 130%。竖屏小地图和「下一站」位于右上角。触屏按键大小单独设置。

## 直接下载游玩（玩家入口）

只想直接游玩无需下载整套源码，请前往 GitHub **[Releases（`v2.5.5`）](https://github.com/mizukidesuwa/forzero-budget/releases/tag/v2.5.5)** 下载对应版本：

- **Windows 免安装完整版（强烈推荐，开箱即联机）**：下载 `forzero-budget-windows-x64-2.5.5.zip`（内置便携 `runtime\node.exe`），完整解压后双击 **`启动游戏.bat`** 即可直接本地自动存档与建房联机，**无需电脑提前安装 Node.js**。
- **轻量跨平台版（需自备 Node.js 22+）**：下载 `forzero-budget-2.5.5.zip`，适合已安装 Node.js 22+ 或自行部署常驻服的用户。
- **手机离线单文件版**：下载 `forzero-budget-mobile-2.5.5.html`，直接用手机浏览器打开即可离线游玩。
- **源码与自行构建**：本仓库主干仅保留工程源码与验证脚本，发行产物可通过 `npm run build:release` 在本地 `dist-v2/` 生成。

## 核心特色

- **三大风格化开放地图与 20 条固定赛道**：
  - **深圳大学 · 粤海校区（荔园环骑）**：9 条赛道（含校园环线、图书馆穿行、双湖绿道、杜鹃山爬坡/下坡、荔香公园城景环线、白石科创城际冲刺等）及高风险切线近路。
  - **伦敦 Bloomsbury（UCL）**：7 条赛道（主庭院、双广场、医学区折返、圣潘克拉斯、商街与大英博物馆、学院穿堂等）。
  - **佛山顺德 · 顺峰山公园**：4 条赛道——青云湖环线（含九孔伏波桥与青云塔），以及「神步山爬坡赛」「神步山下坡赛」「顺峰山环山耐力赛」（湖山联动 1.95 km 闭环、3 条高风险窄切捷径、压实碎石独立物理、草地/水域/落崖强制遣返、环湖观光接驳车与公园 10 地标闪送）。
- **120 Hz 物理与双姿态博弈**：
  - 支持自行车（5 槽深度改装：轮胎 / 齿比 / 刹车 / 车架几何 / 冲刺调校 + 4 套流派预设 + 程序化 3D 外观定制）、电动自行车、电动轮椅、越野小摩托。
  - 支持在设置中按局开启「车辆碰撞箱」（与动态车流/巡游车或联机骑手发生实体碰撞）。
  - 自行车根据速度、坡度、转向与冲刺自动切换 **伏身破风（Aero Tuck）** 与 **起身摇车（Out-of-Saddle Sprint）**，四种车型均可在 AI 和联机对手后方蓄尾流，充满后横向切出触发弹弓。
- **新模式与路线工坊（2.4.0–2.5.0）**：
  - **影子追捕 & 联机捉人（1 追 N）**：单人 3 秒快启动非对称追逃与周期雷达扫描；2–4 人联机房支持 3 轮轮换担任捉人者、6 秒先发逃跑窗口、雷达多目标感知与服务端拦截结算。
  - **夜骑盲区**：夜景锁定与关闭常规导航/小地图引导，借助 `B` / `H` 或触屏摇铃触发声呐回声辨位。
  - **可视化点选路线工坊 & 实时速度曲线差值**：俯视地图直接点选深大粤海 / 伦敦 UCL 路网节点生成分享码 `R1...`，配合基于参考采样曲线二分反查的实时毫秒差值（`liveDeltaMs`），混段对比更准确。
- **种子赛道 v2、每周挑战与地图风场**：
  - `S2-*` / `U2-*` 确定性随机生成合规赛道；每周挑战按本地周历锁定种子并绑定动态天气与风场；常规单人与联机房间也均支持自由调节地图风速（`0–15 m/s`）与 8 方位风向。
- **幽灵竞速、复盘单练与全勋章**：
  - `.ghost.json` 影子文件导出/导入、多影子同场群跑、实时滚动毫秒差、紫牌大师挑战（`0.90 × 金牌时间`）、俯视图走线对比与任意检查点区间「单练」。
- **局域网 P2P 好友联机**：
  - 基于 Node.js 内置 HTTP + SSE + WebRTC DataChannel，覆盖深大粤海、伦敦 UCL 与顺峰山公园三张地图，支持 BO1 / BO3 / 五轮积分联赛 / 盲盒随机 / 四项全能，支持房主自定义赛前**改车时间（0–180s）**与**车辆碰撞箱**开关。
- **全代码 Web Audio 音效与多端自适应**：
  - 内置合成风噪、胎噪、棘轮声（可在设置中静音），支持 `sound/` 自定义音频替换；桌面多文件版与手机单文件离线版全触屏适配。
  - **精简 HUD 与移动端大触屏操控**：速度表专注显示路段位置、路面类型（`柏油 / 碎石 / 草地`）、速度、坡度、冲刺与抓地条（移除冗余 `rpm`，破风/摇车状态仅在触发时浮现于速度表上方）；手机端采用 L 形大按键布局、扩边热区与滑动切键（左/右转滑动换向、加速上滑进冲刺），支持在「设置」调节 **触屏按键大小（紧凑 / 标准 / 超大）** 与查看内置二级菜单 **「玩法说明」**。

## 操作指南

| 按键 / 触屏 | 功能 |
| --- | --- |
| `W` `A` `S` `D` / 方向键 | 加速、转向、刹车 / 停车长按倒车 |
| `Shift` | 自行车冲刺 / 越野车甩尾 / 电自超频 / 电动轮椅爆发 |
| `M` | 打开 / 关闭俯视导览地图（支持「看赛道」与海拔剖面） |
| `R` | 开始 / 重新开始当前计时赛 |
| `P` | 暂停 / 继续 |
| `F` | 回归赛道（+2 秒罚时） |
| `B` / `H` | 摇车铃 |
| `Esc` | 打开 / 关闭设置与车库（设置右上角可进入二级「玩法说明」） |
| 触屏滑动 | 左手滑动切换左右转向；右手「加速」上滑发动当前车型技能，左滑刹车 |

## 本地运行方式

### 1. 桌面完整版（推荐，支持本地自动存档与好友联机）
- 从 GitHub Releases 下载并完整解压 **`forzero-budget-windows-x64-2.5.5.zip`**（免装 Node.js）或轻量版 `forzero-budget-2.5.5.zip`（或自行执行 `npm run build:release:win` / 打开 `dist-v2/desktop/`）：
  - **Windows 一键启动**：双击 **`启动游戏.bat`**（优先调用包内 `runtime\node.exe`，自动启动本地应用壳并将存档同步至 `save/player-data.json`，关闭网页约 8 秒后后台自动退出；若轻量版未检测到 Node.js 会降级打开 `index.html`）。
  - **直接浏览器游玩**：直接用现代浏览器打开 `index.html`（支持 `file://` 离线单人游玩与导入/导出 JSON 备份）。
  - **常驻服务部署**（需要 Node.js 22+）：
    ```sh
    cd forzero-budget-2.5.5
    HOST=127.0.0.1 PORT=8787 node server.mjs
    ```

### 2. 手机单文件离线版
- 从 GitHub Releases 下载 `forzero-budget-mobile-2.5.5.html`（或自行构建后取 `dist-v2/forzero-budget-mobile-2.5.5.html`）发送至手机，使用 Chrome / Edge / Safari 或系统浏览器打开即可离线游玩（支持竖屏与横屏触屏）。

### 3. 本地构建与自动化测试

```powershell
npm ci
npm run build:release
npm run lint
npm test -- --skip-build
npm run verify:all
npm run release:stage -- --skip-build
```

首次用启动器打开 2.5.5 会按版本查找同级轻量版和 Windows 免安装版的存档目录，优先读取 `2.5.4`、`2.5.3`、`2.5.2`、`2.5.1.1`、`2.5.1`、`2.5.0`、`2.4.0`、`2.3.4` 及更早版本的存档。也可以从设置中导入 JSON 备份。
