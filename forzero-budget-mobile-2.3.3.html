    操控与触屏

    • 电脑：W A S D 或方向键骑行，Shift 冲刺，F 回赛道（+2 秒），M 俯视地图，P 暂停，B / H 摇车铃。
    • 手机：左手「左转 ↔ 右转」支持拇指直接滑动切换；右手「加速」上滑进「冲刺」、左滑切「刹车」，按键外缘自带扩边容错热区。
    • 在「设置」里可将 HUD 和触屏按键分别调到 50%–150%。
    • 点击主界面的 1P、2P 或 3P 按钮循环切换车手视线、前方回看和后方跟随。电脑也可以按 V。

    姿态与破风

    • 高速巡航自动进入「伏身破风」（降风阻、提极速），坡道低速或冲刺触发「起身摇车」（提爆发力）；仅在触发时显示于速度表上方。
    • 紧跟前方 AI 或联机对手 2–12 米可触发「尾流破风」，降低空气阻力并加快冲刺耐力回复。

    路面、抓地与遣返

    • 柏油路面极速最高，碎石路面需提前减速与渐进制动，草地会明显降速；左下角「抓地」进度条变橙/红时表示接近侧滑极限。
    • 在车库可比较不同载具的碎石极速和抓地。顺峰山湖心亭从青云塔山脚一侧上栈道，低速居中通过。
    • 顺峰山落水或冲出山路悬崖会触发强制遣返（计时赛 +2 秒罚时，自由骑行传回最近路面）。

    模式、工坊与联机

    • 支持深圳大学、伦敦 UCL 与顺峰山三站直达，可玩自由骑行 / 闪送打卡 / 计时赛（含区间单练与 0.90× 紫牌大师）/ 周赛种子 / 友人多影子对战。
    • 「车库」支持流派预设、5 槽配件取舍调校与外观定制；「联机」支持 BO1 / BO3 / 积分联赛 / 盲盒随机 / 四项全能及赛前改车、车流、风场与碰撞箱规则。

    完赛或退出后可更换载具与配件。
