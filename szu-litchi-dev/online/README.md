# FORZERO: BUDGET · 有限竞速：地贫线 2.1.1

联机请统一使用 2.1.1（协议 v3）。房主可选不限预算、¥400、¥700 或允许违禁魔改，并可开启每轮盲盒预算与确定性阵风。服务端核对配车后锁定本轮配置。

在 **深圳大学 · 粤海校区（荔园环骑）**、**伦敦 Bloomsbury（UCL）** 与 **佛山顺德 · 顺峰山公园** 之间自由骑行与计时竞速。自由骑行时点「到深大站」（伦敦与顺德显示当地站名），再点「选择目的地」，从任一站可直达其余两站。顺峰山公园在牌坊广场下车，选择「青云湖环线」即可使用当前车辆开始计时。三地图现已全部支持联机房间、自定义赛前改车时间与车辆碰撞箱房规。

顺峰山包含「青云湖环线」「神步山爬坡赛」「神步山下坡赛」「顺峰山环山耐力赛」，均使用车库中的当前车辆和改装。自由骑行中可沿伏波桥侧进山，过观景台后从另一侧下山回到湖边；落水或冲出山路悬崖时会自动触发强制遣返赛道。

## 怎么玩（一步到位）

双击本目录的 **`启动游戏.bat`**，会自动打开游戏网页，**不留命令行黑框**，关闭网页约 8 秒后后台自动退出（按 `F5` 刷新网页不会退出）：

- **三大开放地图 20 条固定赛道 + 种子赛道 v2（`S2-*` / `U2-*`）**：
  - 深大粤海 9 条（含「荔香公园城景环线」「白石科创城际冲刺」）、伦敦 UCL 7 条（含「医学区折返冲刺」「圣潘克拉斯与三广场」「商街书店与大英博」「学院穿堂速通赛」）、佛山顺德顺峰山公园 4 条（含「青云湖环线」「神步山爬坡赛」「神步山下坡赛」「顺峰山环山耐力赛」）。
  - 「种子赛道 / 每周挑战」已接入深大荔香公园/深南大道/白石路与 UCL 圣潘克拉斯/Tavistock 北侧/医学区/Brunei 穿堂路网（新版种子码以 `S2-` / `U2-` 开头）。
  - **周赛绑定动态环境**：每周挑战按周种子自动锁定绑定天气与风向风速（`1.0–2.4 m/s`，逆风增阻/顺风提速），支持常规单人与联机调节地图风场（`0–15 m/s`）。
- **单人骑行 / 计时、全车型改装、紫牌挑战与校园闪送**：
  - 打开直接骑，不会对外开启任何联机端口；左上与左下简洁展示赛道、路段位置与路面状态（`柏油 / 碎石 / 草地`），右上角「退出比赛 / 返回自由骑行」仅在比赛或结算时出现；更多技巧可点「设置 → 玩法说明」查看。
  - **全载具数值与调校**：电动自行车 · 新国标原厂默认 `25 km/h`（可选「标准输出」提升至 **48 km/h**），电动轮椅巡航极速 **36 km/h**，越野小摩托 **63 km/h**。
  - 「车库」统一显示路面极速和调校能力。自行车有四套预设、五槽性能调校和外观定制，包括 **「紫水晶 · 限定」**（6 枚金牌+或 1 枚紫牌解锁）与 **「暗曜金 · 大师」**（1 枚紫牌解锁）车漆。
  - **紫牌大师挑战与 20 赛道勋章总览**：在金牌之上新增 **紫牌**（`0.90 × 金牌时间`）；点击顶部 **「勋章」** 可查看三图 20 条赛道勋章进度并一键直达赛道。
  - **实时滚动差值 & 动态车流尾流**：计时赛全程在检查点之间实时插值显示相对参考影子的领先/落后秒数；深大校外道路沿线动态车流支持紧跟车辆触发 **尾流破风**。
  - **自由骑行「校园闪送 / 地标打卡」**：点击 **「闪送」**，在深大、UCL 或顺峰山各 10 处地标间送单。时限按距离、车型和高差计算。
  - **友人对战 · 多影子同场群跑**：在友人对战列表中可勾选 2–3 条同赛道兼容影子一键 **「多影子群跑」**，同场渲染多车模型与昵称标牌。
  - **Web Audio 动态骑行音效**：纯代码实时合成风噪、草地/刹车声与滑行飞轮棘轮声，可在「设置」中一键静音。
  - 发车区可选单人计时、AI 车队赛或 1v1。AI 成绩独立结算。完赛点 **「俯视图走线对比」**，可拖动时间轴、暂停和切换 1×/2×。
- **本地存档与版本迁移**：
  - 通过 `启动游戏.bat` 启动时，个人最佳、车库改装、骑手资料与友人对战会自动同步至本目录的 **`save/player-data.json`**，不依赖浏览器端口。
  - 新版本尚无存档时，启动器优先读取同级 `2.0.0`、`1.9.1.1`、`1.9.1`、`1.9.0`、`1.8.8`、`1.8.7` 和其他已支持的旧版本存档。
  - 也可在「设置」里随时点 **「导出备份 / 导入备份」**，换电脑或跨版本迁移只需导入该 JSON 文件（或直接复制 `save/` 文件夹）。
- **自己建房（房主）**：
  1. 点 **「联机」**，选好赛制、车型房规（统一自行车 / 越野小摩托 / 电动自行车 / 电动轮椅 / 自由混选）和天气，点 **「创建房间」** 自动开启联机端口。
  2. 大厅或轮间房主可直接切换 **地图 / 赛道 / 摇新种子 / 车型 / 天气 / 改车时间 / 车辆碰撞箱 / 地图风速与风向（`0–15 m/s`）**，无需退房重开；进入改车倒计时或准备前所有人均可点 **「车库改装」** 更换涂装与配件并实时同步。
  3. 比赛中支持 **3D 实色车漆与头顶昵称牌**、**实时排名 HUD** 以及 **自行车尾流破风**（紧跟前车 2–12 米降风阻并加快冲刺回能）。
  4. 玩完点 **「退出房间」** 自动关闭联机端口；直接关掉网页也会自动关闭房间并清理后台进程。
- **加入好友房间（客机）**：
  - **方式一（推荐，保留自己的车库改装和个人成绩）**：双击自己电脑的 `启动游戏.bat`（或 `index.html`）→ 点「联机」→ 填入房主的虚拟局域网 / 局域网 IP（如 `26.0.0.10`，默认端口 `8787` 可省略）和 8 位房间码 → 点「加入房间」。
  - **方式二（没下载游戏文件夹时）**：直接用浏览器打开房主发来的邀请链接（例如 `http://26.0.0.10:8787/#room=ABCD2345`），免下载直接进房。
- **手机端游玩（竖屏 / 横屏触屏自适应）**：
  - **和电脑局域网联机**：房主电脑启动 `启动游戏.bat` 并创建房间后，同一 Wi-Fi 或手机热点下的手机浏览器直接打开房主发来的局域网链接（`http://电脑局域网IP:8787/#room=房间码`）即可免下载开骑（横屏自动将速度表与小地图内收至两侧按键内缘，避免遮挡）。
  - **手机触屏操作与按键大小**：左手「左转 / 右转」支持拇指直接左右滑切换，右手「加速」大键上滑可直接进「冲刺」、左滑「刹车」；可在「设置 → 触屏按键大小」切换 **紧凑 / 标准 / 超大** 档位。
  - **手机 HUD 缩放**：「设置 → HUD 缩放」单独调节计时、速度和小地图大小。竖屏小地图与「下一站」位于右上角。
  - **手机单人离线骑行**：直接将根目录的单文件版本 **`forzero-budget-mobile-2.1.1.html`** 发给手机，在系统浏览器 / Chrome / Edge / Safari 中打开即可畅玩，个人成绩与改装存在浏览器本地，也可通过「设置 → 导出/导入备份」迁移存档。
- **自定义音效（可选）**：
  - 默认内置轻量化提示音（倒计时、发车、检查点、完赛、摇铃等），如需替换为自定义音频，可按 `sound/README.txt` 说明将 `countdown` / `go` / `checkpoint` / `finish` / `bell`（按 `B` 或 `H` 摇铃） / `rejoin` 的音频文件放入本目录 `sound/` 下并刷新页面。

> 运行环境：建房功能需要本机安装 Node.js 22+（或将官方便携版 `node.exe` 放到 `runtime\node.exe`）。未安装 Node 时，双击 `启动游戏.bat` 会自动降级直接打开 `index.html`。

## 赛制与规则

2–4 人全部建立连接并准备后由房主发车，每轮全员完赛或退出后公布排名，按 `F` 回归计入 2 秒罚时。

| 赛制 | 计分 |
| --- | --- |
| BO1 | 一局，按完赛时间决胜。 |
| BO3 | 最多三局，按胜场排名，提前锁定胜场时自动结束。 |
| 积分联赛 | 五轮累计积分。四人房前四名依次得 4、3、2、1 分，三人房得 3、2、1 分，两人房得 2、1 分，未完赛得 0 分。 |
| 盲盒随机 | 连续三轮积分赛，每轮结束自动生成全新随机种子赛道。 |
| 四项全能 | 连续四轮积分赛，依次锁定自行车、电动自行车、电动轮椅和越野小摩托。每轮独立校验改车预算。 |

## 可选：独立常驻站点部署

```sh
HOST=127.0.0.1 PORT=8787 node server.mjs
```

配合 HTTPS 反向代理将站点、`/sound/` 与 `/online/` 转发至 `127.0.0.1:8787`（SSE 路径 `/online/rooms/*/events` 需保持流式输出）。可通过 `RIDE_ICE_SERVERS`、`RIDE_TURN_URLS` 与 `RIDE_TURN_SECRET` 配置 STUN/TURN。
